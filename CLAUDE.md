## Architecture & Boundaries

- **Single source of truth:** `config/profile.json` owns theme tokens, SVG geometry, wording templates, metric row definitions, language exclusions, and hero banner copy. `queries/` owns GraphQL queries and `templates/` owns SVG structure.
- **Module boundaries:** `scripts/stats_gen/config.py`, `scripts/stats_gen/metrics.py`, and `scripts/stats_gen/svg.py` are pure (no network, no `os` env access, no wall clock); `scripts/stats_gen/github_io.py` is the single HTTP edge; `scripts/generate_stats.py` is the thin wiring CLI.
- **Execution style (Rule 5):** Main execution is a one-shot static SVG pipeline using direct registry dispatch (`CARD_RENDERERS`) rather than an event bus.
- **Generated artifacts:** `assets/hero-banner.svg`, `assets/github-stats.svg`, and `assets/top-langs.svg` are generated by `scripts/generate_stats.py` — do not edit them by hand. (`assets/catportfolio-card.svg` and AI tool SVGs are static hand-authored art.)
