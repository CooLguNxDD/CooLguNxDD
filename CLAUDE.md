## Architecture & Boundaries

- **Single source of truth:** `config/profile.json` owns geometry, wording templates, metric row definitions, language exclusions, and card copy; `config/themes.json` owns CatPortfolio and Catppuccin theme/accent presets; `config/breeds.json` owns the cat breed registry, pattern markings, and pose templates; `queries/` owns GraphQL queries and `templates/` owns SVG structure.
- **Module boundaries:** `scripts/stats_gen/config.py`, `scripts/stats_gen/metrics.py`, `scripts/stats_gen/cats.py`, and `scripts/stats_gen/svg.py` are pure (no network, no `os` env access, no wall clock); `scripts/stats_gen/github_io.py` is the single HTTP edge; `scripts/generate_stats.py` is the thin wiring CLI.
- **Execution style (Rule 5):** Main execution is a one-shot static SVG pipeline using direct registry dispatch (`CARD_RENDERERS`) rather than an event bus.
- **Generated artifacts:** `assets/hero-banner.svg`, `assets/catportfolio-card.svg`, `assets/cat-fleet-strip.svg`, `assets/ai-tools-cat.svg`, `assets/github-stats.svg`, and `assets/top-langs.svg` are generated by `scripts/generate_stats.py` — do not edit them by hand. (AI tool SVGs in `assets/` are static hand-authored art.)
